# 📊 Excel & Google Sheets Portfolio – Data Management Projects

## 📌 Overview

This repository contains a collection of beginner-to-intermediate level **Excel and Google Sheets projects** designed to demonstrate practical skills in data management, financial tracking, reporting, calculations, and dashboard creation.

These projects focus on using spreadsheets to organize data, apply formulas, generate summaries, and present information in a professional and easy-to-understand format.

---

## 📁 Projects Included

### 1. 🎓 Student Marksheet
A student marksheet designed to record subject-wise marks and automatically calculate total marks, percentage, and grade.

**Key Features:**
- Student details
- Subject-wise marks
- Total marks
- Percentage calculation
- Grade calculation
- Result status
